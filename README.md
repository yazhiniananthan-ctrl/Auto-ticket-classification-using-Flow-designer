##TITLE -
Auto ticket classification using Flow designer
##SETUP- 
Created a dedicated Update set named 'Project Update Set' to track and manage all configurations.
##DATA MODEL-
Built a custom table named ,Incident Workflow, (u_incident_workflow)to manage incoming tickets.
##USER INTERFACE -
Configured an automated workflow in Workflow Studio triggered upon new ticket creation. 
##AUTOMATION-
Implemented conditional Logic to auto-classify issues based on short descriptions 
##EXPORT& DEPLOYMENT- 
Finalized the workflow and exported all configurations into a clean, portable XML update set payload. 
##OUTCOME-
Successfully automated ticket routing and classification to reduce manual work and speed up incident resolution.
