In ServiceNow, auto ticket classification means automatically determining attributes of an incoming ticket—such as:

Category

Subcategory

Assignment group

Priority

Impact

Urgency

Service

Configuration item (CI)

Type of request

Whether the ticket should be routed to a particular team

Instead of having an agent manually read every incident and decide where it belongs, Flow Designer can inspect the ticket and automatically make those decisions.

For example:

User submits: "My laptop is connected to Wi-Fi but I cannot access the internet."

The automation could classify it as:

Type             = Incident
Category         = Network
Subcategory      = Wi-Fi
Assignment Group = Network Support
Impact           = 2 - Medium
Urgency          = 2 - Medium
Priority         = 3 - Moderate
